문장실 서버 시제품
Node.js 24 이상이 설치된 Windows에서 압축을 풀고 start.cmd를 실행하세요. 같은 컴퓨터에서 http://127.0.0.1:3817 을 엽니다.
관리자는 강의실 만들기에서 관리자 비밀번호를 정합니다. 강의실 이름(방번호)를 학생에게 전달하세요. 재접속 시 방번호와 관리자 비밀번호를 사용합니다. 학생은 이름과 교번으로 입장하며 첫 접속이 등록입니다. 같은 방의 동명이인은 구별되는 이름을 정하세요.
동료 첨삭 탭에서 원고를 공유하면 같은 방의 다른 생도가 읽고 구절별 의견을 보낼 수 있습니다. 공유 종료 후 새 열람 및 첨삭을 막습니다. 학습퀴즈 탭에서 교수자가 문제를 게시하고 학생이 답안을 제출합니다. 새 문제나 제출 결과를 다시 보려면 탭을 다시 누르세요.
서버 재시작 후 다시 로그인합니다. 기본 DB는 사용자 홈의 .munjang-classroom 폴더에 있습니다. STUDIO_DATA로 별도 저장소를 지정할 수 있습니다. 배포 시 지속 저장 공간을 연결하세요. 기본은 로컬 전용입니다. 운영 서버에서 HOST 및 PORT를 설정하고 HTTPS 프록시를 연결해야 다른 기기로 접속할 수 있습니다. 기본 포트는 3817입니다.
